# Pratheega M — Portfolio Website

A modern, high-performance portfolio website built with **React**, **Vite**, and **Vanilla CSS**. Designed with rich aesthetics, sleek glassmorphism, responsive micro-animations, and live interactive project simulators.

---

## 🌟 Key Features

1. **Rich Modern Aesthetics & Design System**:
   - Curated dark/light theme with ambient glow orbs and subtle grid textures.
   - Glassmorphic navigation bar with scrollspy and mobile-responsive drawer.
   - Profile visual card featuring Pratheega's actual portrait photo with rotating radiant border rings and floating academic badges.
   - Interactive role typewriter animation cycling through key specialties.

2. **Resume & Credentials Integration**:
   - One-click **Download CV** with celebratory confetti animation.
   - Interactive **Resume Modal** supporting both structured digital view and inline PDF embedding.
   - Complete academic background (KRCT B.Tech IT 2024–2028 with 7.0 CGPA, 12th 71.5%, 10th 75%).

3. **Technical Skills Showcase**:
   - Filterable skills grid by category (*Programming Languages*, *Core CS & Algorithms*, *Web & Data*, *Tools*).
   - Visual progress bars and skill mastery descriptions.

4. **Academic Projects Showcase**:
   - **Electricity Bill Management System Using Data Mining**: Consumption pattern clustering and slab tariff computation.
   - **E-Commerce Web Application (Python)**: Dynamic product catalogs and cart logic.
   - **Round Robin CPU Scheduling Algorithm Using Circular Linked List**: Fair time-quantum process scheduling simulation.

   - **Round Robin CPU Scheduler**: Add processes, configure time quantum, run simulation, and view the animated Gantt chart with calculated Turnaround and Waiting Times.

6. **Interactive Contact Section**:
   - One-click copy buttons for Email (`pratheegamageswari@gmail.com`) and Phone (`+91 9952741346`) with tooltip feedback.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/)

### Development Server
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
